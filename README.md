# Шаблон небольшого веб-приложения

Одна страница `index.html` без внешних библиотек: по-русски, крупный шрифт, светлая и тёмная тема, удобно на iPhone и iPad. Сайт работает на GitHub Pages, а приложение на экране «Домой» **обновляется само**: при открытии и при возврате проверяет, не вышла ли новая версия. Если человек ничем не занят — перезагружается сразу, если что-то печатает — показывает плашку «Обновить».

## Новое приложение за 3 минуты с телефона

Всё делается в Safari на сайте github.com (не в приложении GitHub).

**Один раз, для самого шаблона:** откройте `pages-template` → **Settings** → поставьте галочку **Template repository**.

Дальше для каждого нового приложения:

1. Откройте [github.com/maksimmartynov2000-spec/pages-template](https://github.com/maksimmartynov2000-spec/pages-template) → зелёная кнопка **Use this template** → **Create a new repository**.
2. **Repository name** — короткое имя латиницей, например `drobi`. Оно войдёт в адрес. Оставьте **Public** → **Create repository**.
3. В новом репозитории: **Settings** → **Pages** → **Source: Deploy from a branch** → **Branch: `main`**, папка **`/ (root)`** → **Save**.
4. Через 1–2 минуты приложение откроется по адресу `https://maksimmartynov2000-spec.github.io/drobi/`. В Safari: **Поделиться** → **На экран «Домой»**.
5. Откройте Claude Code, выберите новый репозиторий и опишите, каким должно быть приложение. Правила для Claude уже лежат в `CLAUDE.md`.

Ссылку можно отправить ученику — он тоже добавит её на экран «Домой», и обновления будут приходить сами.

## Что внутри

| Файл | Зачем |
|---|---|
| `index.html` | Всё приложение: вёрстка, стили, скрипт. В начале — метка версии `<meta name="app-build">`. |
| `tools/stamp.py` | Ставит метку версии: дата и короткий хэш содержимого. Запускать перед каждым коммитом: `python3 tools/stamp.py`. Если файл не менялся, метка остаётся прежней. `--check` — только проверить. |
| `tools/check.js` | Проверка вида (393 и 744 px, светлая и тёмная тема) и самообновления: `node tools/check.js`. Нужен Playwright. Скриншоты — в `.work/`. |
| `CLAUDE.md` | Правила для Claude во всех приложениях из шаблона. |
| `.nojekyll` | Чтобы GitHub Pages отдавал файлы как есть, без обработки Jekyll. |

## Как работает самообновление

1. `tools/stamp.py` записывает в начало `index.html` метку вида `2026-11-22·8c426d7d`.
2. Приложение при открытии, при возврате на экран и раз в 10 минут скачивает первые 4 КБ свежего `index.html` (с меткой времени в адресе, чтобы обойти кэш) и сравнивает метки.
3. Метка другая → если человек не печатает и приложение не сказало, что занято (`window.appBusy`), страница перезагружается; иначе — плашка «Обновить».
4. Защита от петли: если за 10 минут дважды не удалось перейти на новую версию, остаётся только плашка.

Важно: GitHub Pages обновляет сайт через 1–2 минуты после мержа, а кэширует страницы до 10 минут — поэтому новая версия на устройствах появляется в пределах нескольких минут.
