# Правила для Claude

Этот репозиторий сделан из шаблона `pages-template`. Это небольшое веб-приложение для владельца и его учеников: всё в одном файле `index.html`, сайт отдаёт GitHub Pages из ветки `main`, из корня. Репозиторий **открытый**.

## Как общаться
- По-русски, на «вы», неформально и коротко. Без воды и лишних оговорок.
- Перед большой работой — уточняющие вопросы одним блоком: нумерованный список, у каждого вопроса 2–4 варианта и свой вариант ответа; рекомендуемый пометить «(рекомендую)».
- Не выдумывать факты. Не знаешь — проверь (документация Apple, MDN, GitHub) или так и скажи.
- Если владелец неправ — сказать прямо, с доводами.
- В конце ответа — 2–3 пункта, что можно раскрыть подробнее.

## Как работать
- Каждая правка — своя ветка и PR. Описание PR по-русски: что сделано, как проверено, что посмотреть.
- После «ок» владельца на конкретный PR — смержить его самому (обычный merge в `main`). Сайт обновится через 1–2 минуты, приложения на устройствах подхватят новую версию сами.
- Перед каждым коммитом:
  1. `python3 tools/stamp.py` — обновить метку версии в `index.html`. Без этого приложения на устройствах не узнают о новой версии.
  2. `node tools/check.js` — проверка вида на ширине 393 px (iPhone 15) и 744 px (iPad mini), светлая и тёмная тема, нет прокрутки вбок, нет ошибок, работает самообновление. Скриншоты — в `.work/` (в git не попадают), посмотреть их глазами.
- Если появились новые файлы, которые нужны сайту (картинки и т. п.), — класть рядом с `index.html`; лучше встраивать прямо в него.

## Безопасность — репозиторий открытый
- Никаких паролей, ключей, токенов.
- Никаких личных данных учеников: имён, фамилий, телефонов, почты, оценок, фото. Демо-данные — только вымышленные.
- Данные пользователей живут только на их устройстве (`localStorage`), в репозиторий не попадают.

## Устройство index.html
- В самом начале — `<meta name="app-build" content="ДАТА·ХЭШ">`. Не переносить ниже: приложение скачивает только первые 4 КБ свежего файла и сравнивает метки.
- Блок «самообновление» в скрипте: проверка при открытии, при возврате в приложение и раз в 10 минут. Человек ничем не занят — перезагрузка сразу; занят — плашка «Обновить». «Занят» определяет `isBusy()`: курсор в поле ввода или `window.appBusy()` вернула `true`. В своём приложении дописать в `appBusy` свои условия (идёт тест, открыто окно, несохранённая форма).
- Всё, что вводит человек, сохранять сразу (`store.set`), чтобы обновление ничего не теряло.
- Без внешних библиотек и шрифтов. Крупный шрифт (основной 19 px, поля ввода не меньше 16 px — иначе iPhone приближает), много воздуха, кнопки не меньше 44 px.
- Цвета — через переменные в `:root`; тёмная тема задана дважды (по системе и по выбору) — менять оба места.
